# Копирование email преподавателя

## Цель

Дать пользователю возможность скопировать адрес преподавателя долгим
нажатием в обеих точках интерфейса, где доступна почта:

- на иконке письма в общем списке контактов;
- на кнопке с полным адресом в карточке преподавателя.

## Поведение

- Короткое нажатие сохраняет текущее поведение и открывает внешнее почтовое
  приложение через `mailto:`.
- Долгое нажатие записывает точный email в системный буфер обмена.
- После успешного копирования показывается `SnackBar` с текстом
  «Почта скопирована» примерно на две секунды.
- Долгое нажатие не запускает почтовое приложение.
- Для человека без email элементы почты, как и сейчас, не отображаются.

## Архитектура

Общая логика оформляется одним небольшим переиспользуемым компонентом в
модуле контактов. Компонент получает email и дочерний элемент интерфейса,
обрабатывает долгое нажатие через `Clipboard.setData` и показывает
подтверждение через ближайший `ScaffoldMessenger`.

Существующие обработчики короткого нажатия остаются владельцами запуска
почтового приложения. Это сохраняет текущую обработку ошибок `mailto:` и не
смешивает копирование с внешней навигацией.

## Обработка ошибок

Flutter API буфера обмена не возвращает пользовательскую ошибку при обычном
успешном вызове. Надпись показывается только после завершения записи в буфер.
Существующая надпись «Не удалось открыть почту» остаётся только для ошибки
короткого нажатия.

## Проверка

Widget-тесты должны подтвердить отдельно для списка и карточки преподавателя:

1. долгое нажатие записывает в буфер точный email;
2. появляется текст «Почта скопирована»;
3. элементы без email не получают действие копирования.

После реализации запускаются целевые widget-тесты, полный `flutter test` и
`flutter analyze`.

## Вне объёма

- отдельная видимая кнопка копирования;
- копирование телефона или других полей;
- изменение API и модели данных;
- изменение текста или поведения короткого нажатия.
