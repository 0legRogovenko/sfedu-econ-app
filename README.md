# Эконом ЮФУ

Неофициальное мобильное приложение (iOS + Android) для студентов экономического
факультета Южного федерального университета: расписание, сессия, новости
факультета, справочник преподавателей и деканата, AI-помощник.

> **Неофициальный проект.** Не связан с ЮФУ и его подразделениями, не выражает
> их позицию. Данные забираются из открытых источников (`sfedu.ru`,
> `econ-sfedu.ru`) и могут расходиться с первоисточником — сверяйтесь с
> официальным расписанием факультета.

## Возможности

- **Расписание** — по группам и по преподавателям, офлайн-первый: показывается
  из локального кэша мгновенно, синхронизируется в фоне. Тип недели
  («верхняя/нижняя») и активный модуль берутся из календаря университета, а не
  вычисляются формулой. Переключатель семестра, фильтр подгруппы, избранные
  группы, метка «Сейчас».
- **Сессия** — ближайшие консультации и экзамены группы с аудиториями.
- **Новости** — лента новостей факультета с бесконечной прокруткой и офлайн-кэшем.
- **Контакты** — единый справочник: деканат и преподаватели кафедр, поиск по
  фамилии, почта по кнопке, переход к расписанию преподавателя.
- **Помощник** — вопросы по учёбе, ответы на базе Claude API поверх кураторской
  базы знаний (работает и без ключа — тогда отвечает контактами деканата).

## Как это устроено

Монорепозиторий из двух частей:

```
┌─────────────┐   scrape (docx/PDF/HTML)   ┌──────────────┐   REST + ETag   ┌──────────────┐
│  sfedu.ru   │ ─────────────────────────▶ │   backend/   │ ──────────────▶ │     app/     │
│ econ-sfedu  │   Crawl-delay: 30, вежливо │  FastAPI +   │   /api/... GET  │  Flutter,    │
│    .ru      │                            │  PostgreSQL  │                 │  офлайн-кэш  │
└─────────────┘                            └──────────────┘                 └──────────────┘
                                                  ▲
                                            sqladmin-админка
                                        (база знаний, ручные контакты)
```

- **`backend/`** — FastAPI + SQLAlchemy 2 + PostgreSQL 16. Забирает расписание
  (docx/PDF), новости и составы кафедр с сайтов ЮФУ по расписанию (APScheduler),
  раскладывает в БД и отдаёт приложению read-only ручки с ETag/304. Админка
  (sqladmin) — для базы знаний помощника и ручных полей контактов. AI-помощник
  через Claude API. Подробности: [`backend/README.md`](backend/README.md).
- **`app/`** — Flutter-клиент (Riverpod, go_router, drift, dio). Офлайн-первый:
  весь контент кэшируется локально (drift) и работает без сети. Подробности:
  [`app/README.md`](app/README.md).

## Быстрый старт

Нужны Docker (для БД и бэкенда) и Flutter SDK (для приложения).

### Бэкенд

```bash
cd backend
cp .env.example .env      # задать ADMIN_PASSWORD и SECRET_KEY
docker compose up -d --build
docker compose exec api python -m src.seed   # демо-данные (идемпотентно)
# API:     http://localhost:8000/health
# Админка: http://localhost:8000/admin
```

БД проброшена на хост как **`localhost:5433`** (порт 5432 часто занят локальным
PostgreSQL). Полный гайд, локальный запуск без Docker, парсеры и переменные
окружения — в [`backend/README.md`](backend/README.md).

### Приложение

```bash
cd app
flutter pub get
flutter run                                          # iOS-симулятор / хост
flutter run --dart-define=API_BASE_URL=http://10.0.2.2:8000   # Android-эмулятор
```

Реальное устройство, запуск вне семестра (демо-дата) и прочие нюансы — в
[`app/README.md`](app/README.md).

## Структура репозитория

```
sfedu-econ-app/
├── backend/            FastAPI-бэкенд (см. backend/README.md)
│   ├── src/api/        read-only ручки приложения + помощник
│   ├── src/schedule/   импорт расписания: разбор docx/PDF, модули, недели
│   ├── src/parsers/    новости и справочник сотрудников
│   ├── src/persons/    связывание людей с расписанием (по тексту ячеек)
│   ├── src/services/   AI-помощник
│   └── tests/          pytest
├── app/                Flutter-клиент (см. app/README.md)
│   ├── lib/core/       тема ЮФУ, API-клиент, drift-БД, prefs
│   ├── lib/features/   onboarding, schedule, exams, news, contacts, people,
│   │                   assistant, settings
│   └── test/           flutter test
└── docs/               спека и планы (docs/superpowers/)
```
