# Android-бета «Эконом ЮФУ»: выпуск и фокус-тест

Это закрытая beta `0.1.0-beta.1`. Она не публикуется в Google Play или в
GitHub Releases. APK передаётся участникам только по приватной ссылке.

## Обязательный gate перед сборкой

Бету нельзя выдавать на старых или демонстрационных данных. Сборка начинается
только после того, как ЮФУ опубликовал актуальное расписание на
[официальной странице](https://sfedu.ru/www/stat_pages22.show?p=STD/rasp/D&params=%28p_es_id%3E10000000000000%29).

Ответственный за выпуск должен:

1. Забрать новые документы с официального сайта и завершить импорт без ошибок.
2. Проверить актуальное расписание минимум для одной группы каждого курса и
   каждого доступного направления непосредственно против PDF/DOCX ЮФУ.
3. Проверить консультации и экзамены, календарь недель, границы семестра и
   отсутствие критичных записей в очереди неразобранных ячеек.
4. Убедиться, что HTTPS API отвечает на `/health`, а release-приложение не
   использует localhost, эмуляторный адрес или демонстрационную дату.
5. Пройти основной сценарий на физическом Android-устройстве до передачи APK.

Если хотя бы один пункт не выполнен, выпуск откладывается — ожидание актуальных
данных предпочтительнее недостоверной beta.

## Передача APK

1. Запустить workflow **Android beta APK** вручную в GitHub Actions.
2. Скачать artifact, сверить APK с приложенным файлом `.sha256` (SHA-256) и
   проверить `beta-manifest.txt`.
3. Загрузить APK в хранилище с приватной ссылкой. Не публиковать его как GitHub
   Release и не размещать ссылку в открытом репозитории.
4. Передать участникам APK, номер версии, SHA-256 и этот чек-лист.

## Установка участником

1. Скачать APK только по ссылке организатора фокус-группы.
2. Разрешить установку приложений из **неизвестных источников** только для
   браузера или файлового менеджера, из которого открывается APK.
3. Установить приложение «Эконом ЮФУ» и после установки вернуть запрет на
   неизвестные источники.
4. При обновлении ставить новый APK поверх старого. Если Android сообщает о
   несовпадении подписи, не удалять данные и сообщить организатору: все beta
   должны подписываться одним upload-ключом.

## Чек-лист фокус-группы

- Онбординг: бакалавриат выбирается по курсу, магистратура — по направлению;
  группы и направления не перемешаны и отсортированы.
- Расписание: сверху есть выбор семестра; предметы, преподаватели, аудитории,
  подгруппы и время совпадают с разделом **Официальное расписание ЮФУ**.
- Избранные группы и фильтр подгруппы сохраняются после перезапуска.
- Поиск преподавателя открывает его карточку и расписание без второго
  отдельного справочника.
- Контакты: сначала деканат, затем остальные по алфавиту; email открывается
  кнопкой почты, телефонные номера не показываются.
- Экзамены и консультации относятся к выбранным группе и семестру.
- Офлайн: сначала открыть разделы с сетью, затем отключить сеть и проверить
  кэш расписания, экзаменов, новостей и контактов.
- AI-помощник честно показывает fallback/ошибку сети и не зависает после сбоя.
- Кнопка **«Сообщить об ошибке»** доступна в настройках.

## Как сообщать об ошибке

Приложить:

- версию Android и модель устройства;
- версию приложения из `beta-manifest.txt`;
- выбранные группу, подгруппу и семестр;
- дату/день и ожидаемую запись из официального файла ЮФУ;
- фактическое поведение, шаги воспроизведения и скриншот без персональных
  данных.

Не отправлять пароли, signing key, содержимое `key.properties` или другие
секреты.
